# MaterialX Shader Generation Sample

Small C++ sample to test and to load a MaterialX material and generate shader source for:

- Slang
- GLSL
- HLSL

MaterialX is downloaded automatically with CMake using `FetchContent`.
Slang is taken from the installed Vulkan SDK. You need to make sure you have latest Vulkan LunarSDK.

## Requirements

- CMake 3.26+
- C++20 compiler
- Vulkan SDK
- Slang included with the Vulkan SDK

Make sure `VULKAN_SDK` is set in your environment variable with the correct path to your root VulkanSDK folder.

## Build

### Windows

```powershell
cmake -S . -B build
cmake --build build --config Release
```

Run:

```powershell
# For the sake of example I am just writing the executable name
# But you need to specify the proper paths for these resources.
MaterialXCodegen example01.mtlx
```

### Linux

```bash
cmake -S . -B build
cmake --build build -j
```

Run:

```bash
MaterialXCodegen example01.mtlx
```

You can optionally specify a material name and output directory:

```bash
MaterialXCodegen <file.mtlx> [material-name] [output-directory]
```

For example:

```bash
MaterialXCodegen example02.mtlx TexturedPBR generated
```

## How It Works

The program just loads a `.mtlx` document together with MaterialX libraries and selects a material from the document.
The generated files are written to where executable is located or the specified directory if any.

GLSL and Slang are generated directly by MaterialX.
HLSL is generated by taking the MaterialX-generated Slang source and transpiling it through the Slang compiler included with the Vulkan SDK.

## Samples

### `example01.mtlx`

A minimal PBR material using `standard_surface`.

It uses constant values for:

- Base color
- Metalness
- Roughness
- IOR

### `example02.mtlx`

A textured PBR material.

It demonstrates a more realistic material graph using texture nodes for:

- Base color
- Metalness
- Roughness
- Normal mapping
